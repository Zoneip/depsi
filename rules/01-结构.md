## 依赖方向（单向，禁止回指）

```text
cli.py ──► pipeline.py ──► steps/ ──► core/ ──► io/
                              │          │
                              └──────────┴──► numpy / scipy / (numba)
simulate.py ──► io/            （生成器只写文件，不调 steps）
tests/ ──► 任意
benchmarks/ ──► 任意（只读）
```

- `core/` 不得 import `steps/`；`io/` 不得 import 数值模块。
- `steps/` 之间禁止互相 import，编排一律在 `pipeline.py`。
- `reference/matlab/` 与 `reference/python/` 只供人读，不得被 `src/` import。
- 未来 Rust 版本在 `rust` 分支开发；跨语言共享 `specs/`、`rules/`、`docs/` 与 `benchmarks/`。

## 命名

- 模块：`snake_case.py`；处理组文件与 MATLAB 模块对应，名字直译（`selection` ← `ps_selection.m`）。
- 公开 API 放各包 `__all__`；以 `_` 开头的模块/函数视为内部（`_reference.py`、`_kernels.py` 是唯一例外，供测试直接引用）。
- 数据类：`@dataclass`，字段名保持与 MATLAB 变量可对照（`dpsc_phase`、`h2ph`、`acheck`）。
