# 01 · 结构与依赖

## 依赖方向（单向，禁止回指）

```text
cli.py ──► pipeline.py ──► steps/ ──► core/ ──► io/
                              │          │
                              └──────────┴──► numpy / scipy / (numba)
simulate.py ──► io/            （生成器只写文件，不调 steps）
tests/ ──► 任意
benchmarks/ ──► 任意（只读）
```

- `core/` 不得 import `steps/`；`io/` 不得 import 数值模块。
- `steps/` 之间禁止互相 import，编排一律在 `pipeline.py`。
- `reference/`（MATLAB 源码）只供人读，不得被 `src/` import。

## 命名

- 模块：`snake_case.py`；处理组文件与 MATLAB 模块对应，名字直译（`selection` ← `ps_selection.m`）。
- 公开 API 放各包 `__all__`；以 `_` 开头的模块/函数视为内部（`_reference.py`、`_kernels.py` 是唯一例外，供测试直接引用）。
- 数据类：`@dataclass`，字段名保持与 MATLAB 变量可对照（`dpsc_phase`、`h2ph`、`acheck`）。

## 新增文件归属

| 想加的东西 | 放哪 |
| --- | --- |
| 新的数值核 | `core/`（+ `_reference.py` 放纯 numpy 版，`_kernels.py` 放编译版） |
| 新的处理步骤 | `steps/`，一文件一组 |
| 对拍/差异记录 | `docs/parity.md`（追加，不改历史条目） |
| 方案与任务 | `specs/SPEC-*.md`；架构决策 `specs/ADR-*.md` |
| 报告/图表产物 | `benchmarks/out/` 或 `docs/figures/`（不入库的写进 `.gitignore`） |

## 禁止

- 在 `src/` 里写死绝对路径或用户目录。
- 引入未在 `pyproject.toml` 声明的依赖（含可选依赖需登记在 extras）。
- 把中间产物（`*.raw`、`*.npz`、`runs/`）提交进仓库。
