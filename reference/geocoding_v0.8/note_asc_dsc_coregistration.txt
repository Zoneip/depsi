NOTE on how to coregister PS.map that corresponds to orbit_1, to
orbit_2 and DESCRIPTION of toolbox functions.

----
orbit_1: metadata and interpolated and normalized orbit of master #1
orbit_2: metadata and interpolated and normalized orbit of master #2
----


PROCEDURE:
-------------------------------------------------------------------
(l,p,h)(1)       ---[lph2xyz, orbit_1]---> (X,Y,Z)(general)

(X,Y,Z)(general) ----[xyz2t, orbit_2]----> (t_a,t_r)(2)

(t_a,t_r)(2)     -----[t2lp, orbit_2]----> (l,p)(h)(2,1)

(1): orbit_1
(2): orbit_2


FUNCTIONS: list of functions with their brief description:


function [image, orbit] = metadata(result_file) 
-----------------------------------------------
DESCRIPTION: greps and dumps metadata and orbit from input result file
to corresponding (vector) variables, streams used, works nice on
small size files.

function [norm_orbit,norm_orbit_line] = intrp_orbit(line,image,precorb)
-----------------------------------------------
DESCRIPTION: normalizes and interpolates orbit, function also dumps
normalized XYZ point on the orbit corresponding an input line. image
variable represents metadata vector created with metadata.m
function. In Matlabs interp1 function linear interpolator used, with
this one I obtained the most optimal results in terms of
residuals. Other options are splines of certain degree. Strange?!?!
Note that this function is suboptimal in cases where the large lines
is used as input file, since for each line orbit is again interpolated
and normalized.

function [xyz] = lph2xyz(line,pixel,height,ellipsoid,image,...
			norm_orbit_line,MAXITER,CRITERPOS)
-----------------------------------------------
DESCRIPTION: Conversion of (lph) to (xyz) coordinate on the reference
ellipsoid (WGS84 assumed). [image] and [norm_orbit_line]
is output of  metadata.m and intrp_orbit.m. MAXITER and CRITERPOS are
interpolator exit criteria.

function [t_azi,t_ran] = xyz2t(xyz_vec,image,orbit,MAXITER,CRITERPOS)
-----------------------------------------------
DESCRIPTION: converts (xyz) to azimuth and range time for input
orbit. [xyz_vec] is standing vector (check this?). [image] and [orbit]
are outputs from previous steps. I think [orbit] variable should be
normalized one. CHECK whether input orbit should be normalized or not,
depends on the interpolator used.

function [line,pixel] = t2lp(t_azi,t_ran,image)
-----------------------------------------------
DESCRIPTION: straightforward transformation of time information into
(l,p), PRF and RSR that are entries of image.vector.input (dumped with
metadata are used)

function [x,y,z] = ell2xyz(ellipsoid,phi,lambda,height)
------------------------------------------------------
DESCRIPTION: converts geodetic coordinate phi,lambda,height to
geocentered cartesian coordinate

function [phi_lam_height] = xyz2ell(position,ellipsoid)
-------------------------------------------------------
DESCRIPTION: conversion xyz -> phi,lam,height
