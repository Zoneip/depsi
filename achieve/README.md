# achieve/ · 归档区

只放**不再是当前入口**的材料，映射 `rules/` / `specs/` / `docs/` 的结构：

```text
achieve/
├── rules/
├── specs/
└── docs/
```

## 规则

1. 归档 ≠ 已实施：归档只表示「不再是现行入口」，其中方案可能并未实施。
2. 归档前必须把仍有效的结论、未完成项、风险、待决事项提炼回现行入口。
3. 归档时记录：原路径、归档路径、原因、日期。
4. **删除归档内容必须先询问用户**；默认只归档不删。
5. 现行文档不得依赖归档文件作为当前事实。
